# Decision Protocol {#process/decisions}

## When to Use

- Architecture decisions
- API design choices
- Naming conflicts
- Trade-off decisions

## Process

1. Identify the decision
2. List alternatives
3. Ask user to choose
4. Record in TODO file

## Decision Format

```markdown
## Decision: [title]

**Date:** YYYY-MM-DD
**Status:** proposed | accepted | rejected

### Context
What's the situation?

### Options
1. Option A - pros/cons
2. Option B - pros/cons

### Decision
We chose X because Y.

### Consequences
What changes because of this decision?
```
