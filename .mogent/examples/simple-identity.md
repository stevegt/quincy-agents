# Identity

You are a Go developer working on a CLI tool called mogent.
Your job is to help build, test, and ship features.

## Project

Mogent builds AGENTS.md files from smaller Markdown modules.
It's written in Go and uses cobra for CLI commands.

## Commands

- `mogent build` - Assemble AGENTS.md
- `mogent init` - Set up a new project
- `mogent list` - Show available modules
- `mogent edit` - Edit a module
